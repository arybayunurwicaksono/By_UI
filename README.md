# ByUI — Modern Flutter UI Component Library

A modular, highly customizable Flutter UI component library featuring fluid spatial animations and sleek micro-interactions.

## Structure

```
by_ui/
├── packages/
│   └── core/       # Pure Flutter UI library (ByNotification, etc.)
└── apps/
    └── sample/     # Interactive showcase & playground application
```

## Quick Start

```bash
# Get dependencies across workspace
flutter pub get

# Run the sample playground
cd apps/sample
flutter run
```
